Draft Accessibility + Legibility Rules

This is what I’d include in the brand guide. It keeps the system usable while preserving the atmospheric grid/grain language.

Usage Standard · Legibility
Atmosphere should never make the work harder to understand.
TextBody and UI text must meet WCAG AA contrast: 4.5:1 minimum for normal text, 3:1 for large display text.
LogoThe primary logo must sit on navy or a sufficiently dark blueprint gradient. Use protected spacing when grids or diagrams become visually active.
GridsGrid lines should remain below 12% opacity in content areas. Use stronger grids only in diagrams, section openers, or technical examples.
GrainGrain must be fine and dense, never chunky. It should reduce banding and add texture without lowering text contrast.
DiagramsFunctional diagrams must prioritize labels and paths. Decorative diagrams may sit behind logos only when they do not cross core logo shapes.
MotionWeb motion should clarify flow. Avoid animation that makes workflow diagrams harder to read or repeats continuously near body copy.
Do/Don'tEvery major visual rule should include a correct and incorrect example so internal users can apply it without interpretation.

Talk through a bottleneck before automating it.
Don’t · active grid, weak contrast
Talk through a bottleneck before automating it.
The guide can state hard contrast rules, then use brand-specific rules for grids, grain, diagrams, and logo placement.
